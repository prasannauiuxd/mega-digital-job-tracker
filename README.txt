MEGA DIGITAL AND ADVERTISING - JOB TRACKER (source)
Developed by Quency Production

FILES
- job-tracker.html : the complete app (one file: all tabs, styles and code). The logo is inside it.
- original-logo.png : the original logo image (for reference).

TABS INSIDE: Today, Work Report, Activity, Jobs, To-Do, Production, Installation, Service, Job Card.

IMPORTANT
- This file is made to run inside Claude (as the published artifact). Saving data, saving PDFs
  and the AI clean-up use Claude's built-in features.
- If you open it directly in a browser, it opens in "demo mode": it works on screen but does
  NOT save data, and PDF saving / AI clean-up will not work.
- PDF maker needs internet (loads jsPDF from cdnjs.cloudflare.com).
- Team password and settings are stored in the app database, not in this file.
- To change this file later, upload it to Claude and ask for the change.
